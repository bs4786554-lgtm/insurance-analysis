# Insurance Charges Analysis

## Project Overview

This project analyzes medical insurance data to understand the factors affecting insurance charges.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset Features

* Age
* Sex
* BMI
* Children
* Smoker
* Region
* Charges

## What I Did

* Cleaned the dataset
* Performed Exploratory Data Analysis (EDA)
* Visualized important relationships
* Built a Machine Learning model
* Evaluated model performance

## Key Insights

* Smokers have significantly higher charges
* BMI and age impact insurance cost
* Region has less impact compared to other features

## How to Run

1. Download the repository
2. Open Jupyter Notebook
3. Run the notebook file
